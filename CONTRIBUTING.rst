Contributing
============

Thank you for considering contributing to Flood App! Contributions of all kinds are
welcome, including bug reports, feature requests, documentation improvements,
and code contributions.

Reporting Issues
----------------

Please report bugs and feature requests via the
`GitHub issue tracker <https://github.com/gantian127/flood_app/issues>`_.

When reporting a bug, it is suggested to include:

- A clear description of the problem
- Steps to reproduce the issue
- Expected and actual behavior
- Relevant error messages or screenshots
- Python version, operating system, and package versions


Pull Requests
--------------------------

1. Fork the repository and clone your fork locally.
2. Create a new branch from main.
3. Make your changes and add or update tests where appropriate.
4. Ensure all tests pass and code style checks are clean.
5. Update documentation if your changes affect user-facing functionality.
6. Open a pull request against main with a clear description of the changes and their purpose.
